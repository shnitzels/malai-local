# מָלֵא

אפליקציית מלאי ביתי מקומית, בעברית ומותאמת קודם כל למובייל.

## מה יש בה

- ניהול כמה מקררים, מקפיאים וארונות.
- הוספה, עריכה, העברה, שימוש ומחיקה של פריטים.
- חיפוש וסינון לפי מקום וסוג מזון.
- פקודות חופשיות בטקסט או בקול בעזרת OpenAI.
- שמירה מקומית בלבד ב־`localStorage`, ללא שרת וללא חשבון.
- התקנה כאפליקציית PWA בסיסית בדפדפנים תומכים.

## OpenAI API Key

אפשר להזין מפתח דרך מסך ההגדרות, או לפתוח פעם אחת כתובת בצורה:

`https://example.github.io/malai-local/?token=YOUR_KEY`

האפליקציה שומרת את המפתח ב־`localStorage` ומסירה מיד את `token` משורת הכתובת באמצעות `history.replaceState`. המפתח עדיין עלול להופיע בהיסטוריית רשת, לוגים או בכלי שיתוף לפני שהעמוד נטען, ולכן הדרך הבטוחה יותר היא מסך ההגדרות. זהו יישום סטטי בצד הלקוח: המפתח והפקודות נשלחים ישירות מהדפדפן ל־OpenAI. אל תשתמשו במפתח ארגוני רחב־הרשאות.

## הרצה מקומית

```bash
python3 -m http.server 8080
```

ואז לפתוח `http://localhost:8080`.

## פרטיות

המלאי, מקומות האחסון וההגדרות נשמרים רק בדפדפן המקומי. אין אנליטיקות ואין backend. בעת שימוש ביכולות AI, הקלטת הקול/הטקסט והקשר רלוונטי של המלאי נשלחים ל־OpenAI לצורך ביצוע הבקשה.
